🚀 Excited to share my latest full-stack project completed as part of the **Sysslan IT Solutions** Full Stack Development Internship Assessment! 

I have designed and developed the **FullStack Event Feedback Management System** — a complete MERN stack application built to streamline event feedback collection and empower organizers with actionable attendee analytics.

### 🌟 Project Highlights:
✅ **All 5 Internship Levels Implemented:**
- **Level 1**: Modern responsive homepage, navigation flow, events showcase, and feedback submission interface.
- **Level 2**: Express.js REST API with health/welcome route (`/api`), feedback handling endpoints, and live feedback display.
- **Level 3**: MongoDB & Mongoose database schema architecture with relational models (`User`, `Event`, `Feedback`).
- **Level 4**: End-to-end integration using Axios, custom Star Rating components, real-time validation, and instant database updates.
- **Level 5**: JWT-protected Admin Portal with full CRUD event management, feedback filtering by event & rating, and satisfaction analytics.

### 🛠️ Tech Stack:
- **Frontend**: React.js 19, Vite, Tailwind CSS, React Router DOM, Axios, Lucide Icons
- **Backend**: Node.js, Express.js RESTful API
- **Database**: MongoDB & Mongoose ODM
- **Security**: JSON Web Tokens (JWT) & bcryptjs password hashing
